# Increment 219.2 — Statistics Three-Tab Layout

Reorganizes the Statistics screen into three top tabs:

- Production
- Paper
- Historical

Each evidence layer now has its own page instead of being stacked vertically.
Production and Paper retain their own Overall Performance and strategy cards.
Historical remains a separate baseline page.

The independent-exposure performance rules from Increment 219.1 remain unchanged.
No performance data is mixed across evidence layers.
